About Us

Prometheon SI is built and operated by the American Business Capital Group, Inc. It is one unified application with five platforms:

  • Prometheon SI — The routed aggregate: one composer over a governed model registry.
  • Legacy Agents SI — The supervised agent pilot: durable agents working under a supervisor.
  • Lampas SI by Pyr Neural Network — The recursive engine: agents that spawn governed generations of agents.
  • Ignis by Pyr Neural Network — The fast lane: a direct model service on the Pyr Neural Network.
  • AI Civilization — The agentic society: a live world of supervisors and workers.

The idea is simple to state and strict in practice: instead of a separate account and a separate app for every model and every agent system, one composer routes work across a governed registry, one Fence governs every agent spawn, and one wallet meters usage at landed cost × 1.35 with the route and token count printed on every answer.

What runs today is a working pilot: routing over a 5,507-record registry with 95 Approved records, Fence-governed recursive spawning verified in live demonstrations, and a staging agent society of Supervisors and Workers. The full beta release is scheduled for February 1, 2027. We describe the system as it is — the registry counts, the verification step, and the limits are published on this site rather than rounded up.
