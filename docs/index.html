Product Info

LLM Aggregate

Prometheon SI routes each prompt over a registry of 5,507 records spanning model types, vendors, models, platforms, and capabilities. 95 of those records are Approved for live routing today. In Auto mode, the router reads the task and picks the model type, then the vendor, then the model; in Manual mode you make those same three picks yourself from the Approved catalog. Output passes a verification step before it reaches you, and every reply is labeled with the route that served it and the tokens the run used.

Recursive Agents

Through Lampas SI, agents can spawn child agents — and further generations — when a job is bigger than one run, including on their own initiative inside the bounds they are given. Recursion is governed by the Fence: every spawn request clears a single check against the registry, budget, and depth limits and comes back GRANTED or DENIED before the child exists. Nothing spawns silently, and every generation stays inside the limits set for the run.

Agentic Society

AI Civilization is a persistent staging society of agents: Supervisors hold roles and delegate, Workers carry out tasks, and the world state changes as they work. Chatting with the society grounds the answer in that live state. Legacy Agents SI provides the supervised lane — durable agents doing defined jobs under a supervisor — and Ignis provides a fast, direct model service. All five platforms share one account, one wallet, and one chat.

Our Process

Input Prompt→Process Manager→Decision Intelligence→Decision Reasoning→Decision Options→Output Generator→Model Output

Every prompt moves through the same pipeline: the Process Manager classifies and decomposes it, Decision Intelligence and Decision Reasoning work out what the task needs, Decision Options selects the model in three steps (1 Model Type → 2 Vendor → 3 Model), and the Output Generator serves and verifies the result.
